# Videos

Coloca aquí tus videos con este formato de nombre:

- `video 01.mp4` → Showreel principal
- `video 02.mp4` → Proyecto 1
- `video 03.mp4` → Proyecto 2
- `video 04.mp4` → Proyecto 3
- `video 05.mp4` → Proyecto 4

La web detectará automáticamente los archivos y los mostrará en las casillas correspondientes. Los números desaparecerán cuando el video se cargue.
